# 📚 SnapClass – AI-Powered Attendance System

**SnapClass** is an AI-powered attendance management system that uses **face recognition and voice biometrics** to automate student attendance.

This repository contains the **SnapClass Landing Page**, which provides an overview of the project, its features, technologies, and the overall system.

## 🌐 Live Website

**SnapClass Landing Page:**
https://sc-landing-page-6e66.vercel.app/

---

## 📖 About the Landing Page

The SnapClass landing page is designed to introduce the project and provide users with a simple overview of the AI-powered attendance system.

It acts as the **front-facing website** for the project and provides information about the system before users access the actual attendance application.

---

## ✨ What the Landing Page Contains

* 📌 Project overview
* 🎯 Problem statement
* 🤖 AI-powered attendance features
* 👨‍🏫 Teacher and student modules
* 🎙️ Face and voice-based verification
* 🛠️ Technologies used
* 🏗️ System architecture / workflow
* 📱 Project information and interface
* 🔗 Link to the live attendance application

---

## 🛠️ Technologies Used

* **HTML** – Page structure
* **CSS** – Styling and layout
* **JavaScript** – Interactive elements
* **Vercel** – Deployment
